# Програмування ESP32: 37 навчальних проєктів

Інтерактивний супровід до навчально-методичного посібника «Програмування мікроконтролера ESP32» за набором Keyestudio ESP32 Learning Kit (KS5011).

Сайт працює через GitHub Pages з файлу `index.html`.

## Що є в кожному проєкті

- інтерактивна анімація принципу роботи (ШІМ, зсувний регістр, АЦП, ультразвук, протокол NEC тощо);
- код з українськими коментарями; пояснення кожного рядка відкривається натисканням;
- «Передбач, перш ніж запустити» (методика PRIMM) з полями для прогнозу;
- типові помилки, самоперевірка з відповідями, завдання трьох рівнів з поступовими підказками.
